Assumptions

Serverfrom youElixirPhoenix + Oban. Concurrency fits a job pipeline.
Platformfrom youiPhone firstApp Store subscriptions pay for tokens.
Scopefrom youArticles in v1, video laterText pipeline first; transcripts reuse it.
Budgetfrom youLow fixed cost≈ $15–35 / month before users.
Tiersfrom youFree · Later+ · StudioVoice quality is what you pay for.
ApprecommendedNative Swift + SwiftUIElixir can't run the phone side. Audio, share sheet, StoreKit need native.
ShaperecommendedOne Phoenix monolithAPI + jobs + webhooks in one deploy. Split later if ever.
JobsrecommendedOban on PostgresRetries, rate limits, no Redis.
HostingrecommendedFly.io, EU regionOne small VM. Hetzner if you want even cheaper.
Audio storagerecommendedCloudflare R2Free egress. Phone downloads directly.
Text AIrecommendedClaude API over ReqNo official Elixir SDK; plain HTTP + JSON output.
VoicerecommendedSwappable TTS adapterElixir behaviour. Vendor picked by blind listening test.
Voice per tierrecommendedDevice · Neural · ElevenLabsFree $0 · Later+ ≈$16/M chars · Studio ≈$50–100/M.
Free summariesrecommendedHaiku 5.5 · capped≈10 / month keeps a free user ≈ $0.03.
PaymentsrecommendedStoreKit 2 + server notificationsNo third-party fee. RevenueCat only if it gets painful.
LoginrecommendedSign in with Apple onlyNo passwords, no email flows.
Cost controlrecommendedLazy + cached + meteredPay on play, cache once, monthly credits per user.
InsightrecommendedPostHog + Sentry free tiersMeasures returns and completions from day one.
PriceopenLater+ $6.99 · Studio $14.99?Try the calculator below.
Studio capopen≈10 full listens / month?Then fall back to Later+ voice. Unlimited loses money.
Studio modelopenElevenLabs Flash or v3?v3 sounds richer, costs ≈2×.
Later+ vendoropenDecided in SpikeAzure vs Google Polish. ElevenLabs is the bar.
iOS minimumopeniOS 17+?SwiftData and Observation need 17.
Video in v1openSave link only?Stored, not processed, until phase 4.
RightsopenShared audio cacheCheck copyright before sharing derived audio across users.
